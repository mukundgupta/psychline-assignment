
The site uses the PaperMod theme as a base but the aesthetics are almost entirely original. It has a black and white theme with a toggle to switch. I have a capsule-like navbar for desktop and a collapsible sliding menu for mobile.
There is a contact page but it currently does not actually submit anywhere. I have also made a contact page for my personal portfolio website which uses formspree to send the submission to my inbox.

Currently the homepage only contains my name with an effect, and the projects are separated into a projects page.

# Setup Instructions
Assuming Hugo is installed (gohugo.io):
- Clone the repository from GitHub or manually install.
- Run `hugo server`
